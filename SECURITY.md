# Security Policy

## This repository

This repository contains Fedora packaging files only — a spec file, build
instructions, and CI configuration. It does not contain, build, or distribute
any application binaries at runtime. There are no credentials, secrets, or
network services.

If you discover a security issue in the packaging itself (e.g., the spec
installs files with incorrect permissions, or the CI workflow exposes
something it shouldn't), please report it by opening a GitHub issue.

## Claude Desktop

For security issues in the Claude Desktop application itself — including the
Electron app, Cowork VM, Claude Code, or any Anthropic service — contact
Anthropic directly through their responsible disclosure program:
https://anthropic.com/responsible-disclosure-policy
